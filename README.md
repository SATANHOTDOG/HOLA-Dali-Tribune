# HOLA 大墩店：脊椎守護與實體物流觀測儀表板
*(Project: Spine-Saver & Mirage-Sales Tribune)*

## 專案緣起
在當代家具零售的偉大演化中，我們見證了兩種突破常理的商業模式：
1. **「期貨化」家具交易**：消費者在門市體驗實品後，需進行為期 4 至 8 個月的「耐心禪修」方能獲得商品。
2. **「去支撐化」人體工學**：為了追求極致的視覺美學，大力推廣無背部支撐點的低背沙發，對當代消費者的核心肌群與坐骨神經提出了前所未有的挑戰。

然而，在年底業績考核的傳統評價體系下，上述兩種前衛的銷售模式，往往造成了評分標準的「超現實主義化」。為了讓真正將「實體商品」交到客人手上、並致力於「預防醫學（推廣 La-Z-Boy 等具備脊椎支撐功能之家具）」的業務同仁，能獲得客觀的數據評價，本系統應運而生。

## 系統功能核心
本儀表板旨在打破考核迷霧，直接對接 Google 雲端試算表之原始銷售數據，提供無濾鏡、無皇室血統加成的絕對業績排名。

* **四大戰略分類（可複選）**：
    * `028 La-Z-Boy` (脊椎守護者指數)
    * `082 家具` (傳統實力指標)
    * `066-003 床墊/床頭片/下墊` (深度睡眠保障)
    * `066-004 Kingsdown/SMS` (頂級休眠護衛)
* **動態排名系統**：精準計算淨業績，排除退貨與虛幻訂單，直列前 30 名真實戰力。
* **深潛查詢功能**：支援以工號或姓名，跨越 30 名的排名結界，強制召喚指定業務員的真實業績數據，拒絕任何「感覺良好」的模糊空間。
* **跨分店聯合觀測**：支援店別篩選，隨時掌握友店的銷售生態與陣亡率。

## 技術架構
* **前端**：純 HTML / CSS / Vanilla JavaScript，極簡暗黑風格，降低閱讀冗員數據時的視覺疲勞。
* **資料源**：Google Sheets API (發布為 CSV)，確保資料同步的絕對即時性。

## 使用聲明
本系統之數據運算邏輯極度生硬且缺乏同理心。若查詢結果導致部分長年依賴「期貨家具」與「空氣業績」獲取高分考核之同仁感到不適，建議其可至門市現場，挑選一張無支撐點之低背沙發靜坐反思。
